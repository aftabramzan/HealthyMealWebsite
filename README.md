# Healthy Meals

A responsive **Healthy Meals landing page** built as a frontend development assessment using **Expo, React Native for Web, TypeScript, and NativeWind**.

The project follows a component-based structure and is designed to provide a polished and responsive experience across desktop, tablet, and mobile screen sizes.

## Tech Stack

* **Expo**
* **React Native**
* **React Native for Web**
* **TypeScript**
* **NativeWind**
* **Vercel** for deployment

## Features

* Responsive navigation
* Hero section with call-to-action buttons
* Statistics and trust indicators
* About / brand introduction
* Meal plans and service cards
* Why choose us / advantages section
* Pricing / growth plans
* How it works section
* Customer testimonials
* Interactive FAQ accordion
* Final call-to-action section
* Responsive footer
* Mobile-friendly layout
* Interactive hover/focus states where applicable

## Run Locally

Clone the repository and install dependencies:

```bash
npm install
```

Start the web application:

```bash
npm run web
```

The application will be available locally through the Expo web development server.

## Production Build

Create the production build:

```bash
npm run build
```

The generated `dist` folder is configured for deployment on Vercel using `vercel.json`.

## Environment Variables

This project does not require any environment variables or private API keys.

No `.env` configuration is required to run or deploy the project.
